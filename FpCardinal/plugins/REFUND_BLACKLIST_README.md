# Refund & Blacklist Plugin

Плагин для автоматического возврата средств и управления черным списком.

## Возможности

### 1. Команда /возврат
Когда покупатель пишет `/возврат` (или `возврат`, `/refund`, `refund`):
- ✅ Отправляется подтверждение о возврате средств
- 🚫 Пользователь добавляется в черный список
- 📊 Сохраняется информация о возврате
- 📱 Отправляется уведомление в Telegram (если настроен)

### 2. Автоматическая блокировка повторных покупок
Если пользователь из ЧС возвратов пытается купить снова:
- 🚫 Заказ автоматически блокируется
- 💰 Средства возвращаются автоматически
- 📨 Пользователь получает уведомление о блокировке
- 📊 Увеличивается счетчик попыток

### 3. Защита от повторных запросов
Если пользователь пишет `/возврат` повторно:
- ⚠️ Получает уведомление, что уже в ЧС
- 📊 Показывается статистика попыток
- 🔢 Увеличивается счетчик попыток

## Установка

1. Скопируй файл `refund_blacklist.py` в папку `FpCardinal/plugins/`
2. Перезапусти FpCardinal
3. Плагин автоматически создаст файл `storage/refund_blacklist.json`

## Использование

### Для покупателя

**Шаг 1:** Напиши в чат команду возврата:
```
/возврат
```

**Шаг 2:** Получишь запрос подтверждения:
```
⚠️ ВНИМАНИЕ! Вы уверены?

Если вы подтвердите возврат средств:
🚫 Вы будете занесены в черный список бота
💰 Средства будут возвращены в течение 24 часов
❌ Повторные покупки будут автоматически отклонены

Вы действительно хотите продолжить?

Напишите:
• "да" - подтвердить возврат и добавление в ЧС
• "нет" - отменить возврат

⏰ У вас есть 5 минут для ответа.
```

**Шаг 3:** Ответь "да" или "нет"

### Варианты ответов

**Подтверждение (любой из вариантов):**
- `да`
- `yes`
- `д`
- `y`
- `ага`
- `угу`
- `+`

**Отмена (любой из вариантов):**
- `нет`
- `no`
- `н`
- `n`
- `отмена`
- `cancel`
- `-`

### Таймаут

Если не ответишь в течение 5 минут:
```
⏰ Время ожидания подтверждения истекло.

Если вы все еще хотите вернуть средства, напишите команду /возврат снова.
```

### Что происходит

**1. Запрос возврата:**
```
⚠️ ВНИМАНИЕ! Вы уверены?

Если вы подтвердите возврат средств:
🚫 Вы будете занесены в черный список бота
💰 Средства будут возвращены в течение 24 часов
❌ Повторные покупки будут автоматически отклонены

⏰ У вас есть 5 минут для ответа.
```

**2. При подтверждении (ответ "да"):**
```
✅ Ваш запрос на возврат средств принят.

💰 Средства будут возвращены в течение 24 часов.
⚠️ Вы добавлены в черный список.
🚫 Повторные покупки будут автоматически возвращены.
```

**3. При отмене (ответ "нет"):**
```
❌ Возврат средств отменен.

Если передумаете, напишите команду /возврат снова.
Рады, что остаетесь с нами! 😊
```

**4. При неправильном ответе:**
```
⚠️ Пожалуйста, ответьте "да" или "нет".

Вы уверены, что хотите вернуть средства и быть добавлены в черный список?
```

**5. При повторной попытке возврата (уже в ЧС):**
```
❌ Вы уже находитесь в черном списке за возврат средств.

📊 Количество попыток возврата: 2
⏰ Первый возврат: 27.01.2026 20:30

⚠️ Повторные покупки будут автоматически возвращены.
```

**6. При попытке повторной покупки:**
```
🚫 ЗАКАЗ ОТКЛОНЕН

Вы находитесь в черном списке за возврат средств.

📊 Информация:
• Первый возврат: 27.01.2026 20:30
• Попыток возврата: 3

💰 Средства будут автоматически возвращены в течение 24 часов.
```

## Интеграция с основным ЧС

Плагин автоматически:
- ✅ Добавляет пользователей в основной черный список Cardinal
- ✅ Синхронизирует ЧС при запуске
- ✅ Сохраняет изменения в `storage/blacklist.json`

```
[Refund & Blacklist] Таймаут подтверждения для Player789

```

## Удаление пользователя из ЧС

Чтобы удалить пользователя из ЧС возвратов:

1. Открой файл `storage/refund_blacklist.json`
2. Удали запись с ником пользователя
3. Удали пользователя из `storage/blacklist.json` (основной ЧС)
4. Перезапусти FpCardinal
